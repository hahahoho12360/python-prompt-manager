# 나만의 프롬프트 관리 프로그램

## 프로젝트 설명

Python과 Git 기초 학습을 위한 콘솔 기반 프롬프트 관리 프로그램입니다.

다양한 AI 프롬프트를 제목, 내용, 카테고리, 즐겨찾기 여부, 조회수와 함께 관리할 수 있습니다.

## 실행 방법

Python 3.10 이상이 설치되어 있어야 합니다.

프로젝트 폴더에서 터미널을 열고 다음 명령을 실행합니다.

```bash
python main.py
```

## 주요 기능

- 프롬프트 추가
- 프롬프트 목록
- 카테고리별 조회
- 프롬프트 검색
- 프롬프트 상세 보기
- 즐겨찾기 관리
- 즐겨찾기 목록
- JSON 저장 및 불러오기
- Markdown 내보내기
- 프롬프트 수정 및 삭제
- 조회수 TOP 목록

## 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 데이터 구조

각 프롬프트는 제목, 내용, 카테고리, 즐겨찾기 여부, 조회수를 저장합니다.

예시는 다음과 같습니다.

```python
{
    "title": "블로그 글 작성 도우미",
    "content": "주어진 주제로 이해하기 쉬운 글을 작성해주세요.",
    "category": "텍스트 생성",
    "favorite": False,
    "view_count": 0
}
```

## 보너스 기능

JSON 저장·불러오기, Markdown 내보내기, 프롬프트 수정·삭제, 조회수 기록 및 TOP 목록을 구현했습니다.
